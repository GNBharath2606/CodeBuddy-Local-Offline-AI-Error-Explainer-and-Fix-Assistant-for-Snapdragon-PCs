# CodeBuddy-Local-Offline-AI-Error-Explainer-and-Fix-Assistant-for-Snapdragon-PCs




CodeBuddy Local
Offline AI error explainer and fix assistant for Snapdragon-powered HP PCs.
Built for the Snapdragon® AI Lab Build & Present Challenge by G N Bharath.
Paste a code snippet and its error message, and CodeBuddy Local explains what went wrong in plain English and suggests a fix. Everything runs on your laptop using a small code LLM accelerated on the Snapdragon NPU. No internet, no API keys, and no code ever leaves your device.
Why
Many students code with unreliable internet.
Pasting coursework or project code into cloud tools raises privacy and cost concerns.
Beginners lose hours to stack traces they cannot read.
